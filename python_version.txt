📝 Memory Trick: The "Personal Assistant" Analogy
• The Terminal: Your desk where you give commands.
• Zsh (The Shell): Your personal assistant. They take your text commands and run to the hard drive to execute them.
• The .zshrc file: The assistant's instruction notebook on the shelf. They only read it when they first wake up.
• An Alias: A nickname or shortcut you force the assistant to memorize.


Step 1: Open the Instruction Notebook
Run this command to open your assistant's instruction notebook (.zshrc) using a built-in terminal text editor (nano):    nano ~/.zshrc



Step 2: Write the New Rules (Aliases)
Scroll to the very bottom of the file using your keyboard's arrow keys. Paste these two lines to create shortcuts pointing to Python 3.13:
alias python3="python3.13"
alias python="python3.13"



Step 3: Save and Close the Notebook
Because you are inside a terminal editor, you must use keyboard shortcuts to save:
1. Press Control + O (This tells the computer to "WriteOut" / save your text).
2. Press Enter (This confirms you want to overwrite the existing file).
3. Press Control + X (This exits the editor and brings you back to the normal prompt).



Step 4: Force the Assistant to Refresh
Your assistant only reads the notebook when they first start up. Force them to reread your new rules immediately by running:  source ~/.zshrc


Step 5: Verify It Worked
Test if your assistant is routing the command to the correct version: python3 --version
