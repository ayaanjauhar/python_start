7.Rules for Python variables:
A variable name must start with a letter or the underscore character
A variable name cannot start with a number
A variable name can only contain alpha-numeric characters and underscores (A-z, 0-9, and _ )
Variable names are case-sensitive (age, Age and AGE are three different variables)
A variable name cannot be any of the Python keywords.
- Camel Case : Each word, except the first, starts with a capital letter:
myVariableName = "John"
- Pascal Case : Each word starts with a capital letter:
MyVariableName = "John"
- Snake Case : Each word is separated by an underscore character:
my_variable_name = "John"

17."Strings are Arrays" simply means nstead of treating "Hello" as one big indivisible blob, Python treats it like a row of boxes, where each box holds one character.Because characters are stored in order, you can grab any individual character using square brackets [] and its position number (index).n languages like C++ or Java, a single letter (like 'A') is a special data type called a char.
Python keeps things simple: it doesn't have a char type. A single letter is just a string with a length of 1.Even though you can look at any character using its index, Python does not allow you to change a character directly inside an existing string.
